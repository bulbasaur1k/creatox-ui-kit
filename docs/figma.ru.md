# Кит в Figma

Источник правды — код. В Figma переезжают две вещи, каждая своим путём: **токены** — плагином из этого репозитория, в переменные с режимами Light и Dark; **компоненты** — с живого листа на GitHub Pages, плагином html.to.design. После релиза кита оба шага повторяются, и макет догоняет код, а не наоборот.

## 1. Токены → переменные

`figma/tokens.figma.json` лежит в репозитории и пересобирается командой

```bash
npm run figma:tokens
```

Это 93 токена из `@theme` с двумя значениями каждый — light и dark. Цвета уже переведены из oklch в то, что понимает Figma.

Плагин — папка `figma/`, ставится как плагин разработчика, без публикации:

1. Figma → меню → **Plugins → Development → Import plugin from manifest…** → выбрать `figma/manifest.json`.
2. Открыть файл библиотеки, запустить **creatox-ui-kit tokens**.
3. Выбрать `figma/tokens.figma.json` (или вставить его содержимое), нажать «Импортировать».

Получится коллекция переменных **creatox-ui-kit** с режимами **Light** и **Dark**:

| Токен в CSS               | Переменная           | Тип                   |
| ------------------------- | -------------------- | --------------------- |
| `--color-accent-hover`    | `color/accent-hover` | Color, два режима     |
| `--spacing-control-md`    | `spacing/control-md` | Number, px (rem × 16) |
| `--radius-control`        | `radius/control`     | Number                |
| `--text-ui`               | `text/ui`            | Number                |
| `--duration-snap`         | `duration/snap`      | Number, мс            |
| `--font-sans`, `--ease-*` | `font/…`, `ease/…`   | String                |

И текстовые стили `text/micro … text/display` — размер, интерлиньяж, трекинг из тех же токенов. Шрифт — первый из стека кита, который найдётся в Figma; для системного стека это будет Inter, если он установлен, — подмените вручную на тот, что используете в макетах.

Повторный импорт **обновляет** значения существующих переменных по имени, ничего не дублирует и не рвёт привязки в макетах. Переменная, которую в коде переименовали, останется в Figma старой — удалить её надо руками.

## 2. Компоненты → лист

Лист для переноса — `demo/sheet.html`: каждый компонент во всех состояниях, размерах и тонах, подписанный, секциями. На Pages он живёт по адресам

- светлая тема: https://bulbasaur1k.github.io/creatox-ui-kit/demo/sheet.html
- тёмная: https://bulbasaur1k.github.io/creatox-ui-kit/demo/sheet.html?theme=dark

Перенос — плагином [html.to.design](https://www.figma.com/community/plugin/1159123024924461424) (сообщество, есть бесплатный уровень):

1. Запустить плагин в файле библиотеки, вкладка **URL**, вставить адрес листа, ширина 1440, импортировать.
2. Плагин привозит страницу слоями с auto layout. Каждая секция листа (`Typography`, `Button`, `Fields`, …) приходит фреймом со своим именем — их и превращать в компоненты: выделить вариант → **Create component**, варианты одной кнопки — **Combine as variants**.
3. Повторить для тёмной темы. Цвета в слоях — обычные заливки; привязать их к переменным из шага 1 можно выделением → цвет → «Apply variable», или плагином, который сопоставляет заливки переменным по значению (Tokens Studio умеет).

Что на лист не попало, потому что живёт в top layer и не рисуется статически: открытые списки `Select`/`Combobox`/`TreeSelect`, `Dialog`, `Sheet`, `Toast`. Их можно снять так же с витрины — `demo/`, — открыв нужный элемент перед импортом (плагин делает снимок текущего DOM).

## 3. Как держать в синхроне

- Релиз кита → `npm run figma:tokens` → импорт плагином → переменные обновлены. Макеты, привязанные к переменным, перекрасятся сами.
- Новый компонент или состояние → он появляется на листе `demo/sheet.tsx` (это часть работы над компонентом, как стори) → дизайнер импортирует секцию заново.
- Спорные пиксели решаются в коде: лист — то, что реально рендерит браузер.

## Чего здесь нет

Автоматической сборки Figma-компонентов из кода — Figma не даёт создать компонент снаружи без плагина, а плагин, рисующий шестьдесят компонентов заново, был бы второй реализацией кита. Лист и html.to.design дают тот же результат за минуты, и остаются честными: в Figma попадает ровно то, что нарисовал браузер.
